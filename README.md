# Cozy Prime Stay

An Airbnb Unit showcase website built with Next.js.

## Features

- Static Site Generation
- Airbnb showcase
- Optimized images
- SEO-ready
- GitHub CI
- Worldwise travel pages(todo)

## Tech Stack

- Next.js (App Router)
- TypeScript
- ESLint
- Prettier
- Husky

## Getting Started

- npm install
- npm run dev

## Deployment

Deploy easily on Vercel.

## Color Palette

- Primary: #1f1f1f
- Accent: #c97b63
- Soft: #f6f3ef
- Text: #444

## Breakpoints

- Mobile: 0–767px
- Tablet: 768px–1024px
- Desktop: 1025px+
