# Airbnb Worldwise

A travel and Airbnb showcase website built with Next.js.

## Features

- Static Site Generation
- Worldwise travel pages
- Airbnb showcase
- Optimized images
- SEO-ready
- GitHub CI

## Tech Stack

- Next.js (App Router)
- TypeScript
- ESLint
- Prettier
- Husky

## Getting Started

npm install
npm run dev

## Deployment

Deploy easily on Vercel.
